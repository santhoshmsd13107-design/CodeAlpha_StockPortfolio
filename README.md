Stock Portfolio Tracker using Python

About the Project

This project is a simple Stock Portfolio Tracker developed using Python. It calculates the total investment value based on manually defined stock prices and user-entered quantities.

Features

- Displays available stocks.
- Accepts stock names from users.
- Accepts stock quantities.
- Calculates individual investment values.
- Calculates total investment value.
- Handles invalid stock names.

Technologies Used

- Python
- Dictionary
- User Input and Output
- If-Else Conditions
- While Loop
- Basic Arithmetic

How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the terminal.
4. Run:

python stock_tracker.py
